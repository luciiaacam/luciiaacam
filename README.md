## Projects

### AMIGA — Diabetes Assistant

**Bachelor's Thesis | In development**

Academic project focused on developing a personalized virtual
assistant for people with Type 1 Diabetes.

The current implementation focuses on:

- Wearable device integration.
- Bluetooth Low Energy communication.
- Real-time heart rate acquisition.
- Native Android monitoring services.
- Local physiological data storage.

Future development includes continuous glucose monitoring,
Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

**Technologies:** Flutter, Dart, Kotlin, SQLite and Polar BLE SDK.

The repository is currently private while the project is under
development.
